# Offlink Roadmap

## Phase 0 — Foundation
Architecture, security, protocol design, CI, verification.

## Phase 1 — Flutter foundation
App shell, theme, navigation, local database, onboarding, identity.

## Phase 2 — BLE discovery
Permissions, advertising, scanning, GATT, peer discovery.

## Phase 3 — Direct encrypted messaging
Handshake, key agreement, encryption, ACK, local queue.

## Phase 4 — Mesh
TTL, deduplication, forwarding, retries, store-and-forward.

## Phase 5 — Groups
Membership and secure group key lifecycle.

## Phase 6 — One-time location
Explicit permission, encrypted location message, recipient display.

## Phase 7 — ESP32
ESP-IDF/NimBLE relay compatible with the Offlink protocol.

## Phase 8 — Hardening
Battery, background behavior, fuzzing, abuse controls, security review.

## Phase 9 — iOS
Only after Android and protocol behavior are stable.

## Out of MVP
- voice/video
- large file transfer
- public profiles
- cloud sync
- advertisements
- analytics
- phone-number accounts
- complex routing algorithms
- full Bluetooth Mesh implementation
